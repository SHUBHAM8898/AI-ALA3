# College Helpdesk Chatbot

Improved beginner-friendly rule-based chatbot.

## Files
- `college_chatbot.py`: Python terminal chatbot using if/elif rules and fuzzy matching for common typos.
- `index.html`: browser demo with quick-topic buttons.
- `College_Chatbot_Report.pdf`: assignment report and sample conversations.

## Run Python chatbot
```bash
python college_chatbot.py
```

## Topics
Admissions, courses/syllabus, fees, exams/results, attendance, library, scholarships, hostel, transport, timetable, faculty, certificates, placements, Wi-Fi/labs, contacts, holidays, documents, complaints, greetings and help.

## Limitations
This is a rule-based chatbot, not a generative AI chatbot. It can answer questions covered by its rules; it cannot truthfully answer every possible question or access live college records. Add more rules or connect a trusted data source to expand it.
